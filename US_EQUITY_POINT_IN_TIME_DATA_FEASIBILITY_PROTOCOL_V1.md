# US Equity Point-in-Time Data Feasibility Protocol v1

## Purpose

This protocol starts the separately governed listed-equity research branch after
the valid terminal Kraken 12h `HOLD_CASH`. It asks only whether a reproducible,
survivorship-aware and point-in-time US-equity research dataset can be assembled
without adding a paid monthly data service.

The boundary is a **$0 monthly data budget**.
**A capability gap does not authorize a purchase.** It records the gap and
returns research to the operator for a later choice among another no-cost
source, a pause or a separately authorized budget.

## No-cost source boundary

The first review may inspect official SEC/EDGAR documentation and public API
schemas. SEC records may support filing availability, as-reported facts,
material-event timestamps and raw institutional filings, but each capability
must be proven rather than inferred from a product description.

The Sharadar free Dow 30 sample is schema-only. It cannot establish historical
universe coverage, delisting coverage, point-in-time industry membership or
performance suitability. No paid Sharadar plan, paid API key, trial requiring
payment details or automatic paid fallback is authorized.

Other public sources may be proposed only as explicit observations with a
reviewed license and zero recurring data cost. Combining sources must preserve a
stable security identity and causal availability timestamps.

## Required capability registry

A no-cost stack is feasible only if its non-sample, license-reviewed sources
jointly prove every capability:

1. stable security identifier across ticker changes;
2. point-in-time filing availability;
3. as-reported quarterly and annual fundamentals;
4. active and delisted security master;
5. active and delisted daily OHLCV;
6. corporate-action and ticker lineage;
7. point-in-time sector and industry classification;
8. material-event availability timestamps;
9. institutional-sponsorship availability timestamps;
10. market calendar and benchmark history;
11. at least ten years of historical coverage; and
12. license permission for immutable bulk research evidence.

Present-day survivors, current index members, revised fundamentals without their
historical availability and back-adjusted prices without corporate-action
lineage cannot satisfy this registry.

## Audit inputs and decisions

Every source observation states its identifier, monthly cost, sample-only role,
license-review state and an exact Boolean value for every required capability.
Missing or extra capability keys, duplicate identifiers and non-Boolean claims
fail closed. Any positive monthly cost is rejected before capability scoring.

Only non-sample sources with reviewed licenses can contribute to the capability
union. A complete union returns `SOURCE_FEASIBLE` and permits only a separate
equity-hypothesis protocol. An incomplete union returns `SOURCE_GAP`, identifies
every missing capability and keeps purchase authorization false.

## Information and execution boundary

No market value, label, return or model is opened or generated by this protocol.
It does not choose a stock universe, reproduce CAN SLIM, define numeric growth or
relative-strength thresholds, run a backtest, train a ranker or select a broker.

The prior Kraken evidence remains immutable.
**Calibration and Evaluation remain unopened.** Candidate v2, portfolio
allocation, PAPER, cloud strategy execution, real orders and live execution
remain unauthorized.

## Controlled sequence

1. implement and statically bind this declaration and pure capability evaluator;
2. reproduce focused and complete tests before integration;
3. separately authorize a read-only documentation/schema audit;
4. inspect no market values and create no model during that audit;
5. record either a complete no-cost source stack or the exact capability gap;
6. require another operator decision before acquisition or hypothesis design.

No subscription, charge, dataset acquisition or performance run is an automatic
consequence of committing this protocol.
